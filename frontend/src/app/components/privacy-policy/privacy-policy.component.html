Política de privacidad

Actualizado: 20 de septiembre de 2026


Medición de audiencia

tx.taxi utiliza Cloudflare Web Analytics para medir las visitas y el rendimiento, y una cookie diaria propia compartida entre sus exploradores para contar cada navegador una vez por día UTC. El recopilador diario de audiencia solo guarda un identificador diario, el nombre de host del explorador y si hubo interacción. No recibe textos de búsqueda, direcciones, ID de transacción, URL ni direcciones IP. Los registros diarios individuales caducan después de 31 días; los recuentos agregados se conservan durante 400 días. Do Not Track y Global Privacy Control desactivan esta medición propia. Detalles y exclusión voluntaria.

Usa tu propio nodo cuando la privacidad sea importante

btc.tx.taxi muestra datos públicos de la cadena y la mempool de Bitcoin mediante el backend configurado por el operador del sitio. Para verificar los datos de forma independiente y obtener la máxima privacidad de red, utiliza tu propio nodo y explorador de Bitcoin.


Datos de las solicitudes

Las solicitudes normales al sitio web y a la API pueden revelar al operador metadatos web habituales, como tu dirección IP, agente de usuario, URL solicitada y hora de la solicitud. Los registros del servidor pueden conservarse para garantizar la fiabilidad, prevenir abusos y solucionar problemas.


Preferencias locales

Las preferencias de visualización, como el tema, la denominación, la moneda fiduciaria, el idioma y la zona horaria, pueden guardarse en tu navegador. btc.tx.taxi no requiere una cuenta para el uso habitual del explorador.


Datos públicos de la cadena de bloques

Las transacciones, direcciones, scripts y bloques de Bitcoin son públicos. Consultar una dirección o transacción puede asociar esa consulta con tus metadatos de red. No consideres un explorador público como una barrera de privacidad.


Enlaces externos

Este sitio enlaza a canales de contacto de tx.taxi, documentación de Bitcoin, el código fuente del proyecto original e información sobre licencias. Esos servicios externos tienen sus propias políticas de privacidad.

Privacy Policy

Updated: September 20, 2026


Audience measurement

tx.taxi uses Cloudflare Web Analytics for page views and performance, and a first-party daily cookie shared across its explorers to count browsers once per UTC day. The daily audience collector stores only a daily identifier, the explorer hostname, and whether there was interaction. It does not receive search text, addresses, transaction IDs, URLs, or IP addresses. Individual daily records expire after 31 days; aggregate counts are retained for 400 days. Do Not Track and Global Privacy Control disable this first-party measurement. Details and opt-out.

Use Your Own Node When Privacy Matters

btc.tx.taxi displays public Bitcoin chain and mempool data through the backend configured by the site operator. For independent verification and the strongest network privacy, use your own Bitcoin node and explorer.


Request Data

Normal website and API requests can reveal standard web metadata to the operator, including your IP address, user agent, requested URL, and request time. Server logs may be retained for reliability, abuse prevention, and debugging.


Local Preferences

Display preferences such as theme, denomination, fiat currency, language, and timezone may be stored in your browser. btc.tx.taxi does not require an account for ordinary explorer use.


Public Blockchain Data

Bitcoin transactions, addresses, scripts, and blocks are public. Looking up an address or transaction can associate that lookup with your network metadata. Do not treat a public explorer as a privacy boundary.


External Links

This site links to tx.taxi contact channels, Bitcoin documentation, upstream source code, and license information. Those external services have their own privacy policies.
