Privacy Policy

Updated: September 20, 2026


Audience measurement

tx.taxi uses Cloudflare Web Analytics for page views and performance, and a first-party daily cookie shared across its explorers to count browsers once per UTC day. The daily audience collector stores only a daily identifier, the explorer hostname, and whether there was interaction. It does not receive search text, addresses, transaction IDs, URLs, or IP addresses. Individual daily records expire after 31 days; aggregate counts are retained for 400 days. Do Not Track and Global Privacy Control disable this first-party measurement. Details and opt-out.

Use Your Own Node When Privacy Matters

btc.tx.taxi displays public Bitcoin chain and mempool data through the backend configured by the site operator. For independent verification and the strongest network privacy, use your own Bitcoin node and explorer.


Request Data

Normal website and API requests can reveal standard web metadata to the operator, including your IP address, user agent, requested URL, and request time. Server logs may be retained for reliability, abuse prevention, and debugging.


Local Preferences

Display preferences such as theme, denomination, fiat currency, language, and timezone may be stored in your browser. btc.tx.taxi does not require an account for ordinary explorer use.


Public Blockchain Data

Bitcoin transactions, addresses, scripts, and blocks are public. Looking up an address or transaction can associate that lookup with your network metadata. Do not treat a public explorer as a privacy boundary.


External Links

This site links to tx.taxi contact channels, Bitcoin documentation, upstream source code, and license information. Those external services have their own privacy policies.
